# F1 Pulse

F1-дашборд с актуальным календарём, личным зачётом, Кубком конструкторов и результатами последнего Гран-при. Данные берутся из Jolpica F1 API, а на сервере кэшируются на 5 минут.

## Запуск на компьютере

```bash
cd /Users/pavel/Documents/Playground/f1-live
python3 server.py
```

Откройте `http://localhost:8000`.

## Публикация через GitHub и Render

### 1. Создать репозиторий

1. Откройте [github.com/new](https://github.com/new).
2. Назовите репозиторий `f1-pulse`, выберите **Public** и нажмите **Create repository**.
3. Нажмите **uploading an existing file** и загрузите *содержимое* этой папки: `index.html`, `server.py`, `render.yaml`, `.gitignore` и `README.md`.
4. Нажмите **Commit changes**.

### 2. Опубликовать на Render

1. Зарегистрируйтесь на [render.com](https://render.com/) через GitHub.
2. Нажмите **New → Blueprint** и выберите репозиторий `f1-pulse`.
3. Render сам прочитает `render.yaml`. Подтвердите создание сервиса на плане **Free**.
4. Дождитесь статуса **Live** и скопируйте выданный адрес `https://...onrender.com`.

Это и будет публичная ссылка на сайт. После любых изменений в GitHub Render автоматически опубликует новую версию.

> На бесплатном Render сервер засыпает после 15 минут без посетителей. При первом открытии после простоя запуск занимает примерно минуту.
